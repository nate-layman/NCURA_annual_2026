Why GPUs?

CPUs were built to work on a few challenging problems at a time.

CPU
GPU

GPUs were built for displaying graphics, which involves solving millions of relatively easy problems at once.

LLM processing also involves solving millions of relatively easy problems in parallel so LLMs run best on GPUs. Which is why running a model locally takes a special kind of computer.

Can they run on your laptop? Yes, but painfully slowly.

How an LLM answers a question

Text in, tokens through a neural network, text out.

1. Input

A user types a plain-text prompt.

"What is a grant?"
↓

2. Tokenization

The text is split into tokens: short character chunks the model was trained on. Each token maps to an integer ID.

What is a grant?
→ [3923, 374, 264, 13500, 30]
↓

3. Processing

Each token becomes a vector. Dozens of transformer layers use attention to weigh how tokens relate. The final layer scores every possible next token. Why do LLMs run on GPUs?

embed → attention × N → next-token probabilities
"A" 0.41"Grants" 0.22"Funding" 0.08 …
↓

4. De-tokenization

One token is picked and appended to the sequence. The model runs again to pick the next one, and the next, until it stops. The final token IDs are mapped back to text.

[32, 7666, 374, 264, …]
→
A grant is a …
↓

5. Output

The decoded text is streamed back to the user.

"A grant is a sum of money awarded to support a specific project, typically by a government agency or foundation."
